Ce projet de bibliothèque universitaire hybride met en œuvre, dans le cadre de l’examen, deux interfaces complémentaires : une API REST exposée aux étudiants et aux enseignants pour consulter le catalogue, vérifier la disponibilité et réserver des ouvrages, et une API SOAP dédiée aux bibliothécaires pour gérer les stocks, les prêts et les retours. Développé en Java avec Spring Boot et Spring-WS, il s’appuie sur une base de données PostgreSQL (ou H2 en mémoire) partagée par les deux services, garantissant cohérence et performance. L’articulation REST/SOAP illustre la maîtrise des standards web et la capacité à concevoir une architecture modulaire, robuste et évolutive.
